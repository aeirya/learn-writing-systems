# Armenian handwriting images

Original SVGs: [Wikimedia Commons collection](https://commons.wikimedia.org/wiki/Category:Armenian_handwritten_upper-_and_lower-case_pairs_with_font_lines), by [そらみみ](https://commons.wikimedia.org/wiki/User:そらみみ), licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Files retain their original contents, names, and license; the site's GPL does not replace the artwork license. Each source file is at https://commons.wikimedia.org/wiki/File: followed by its filename.

To download the 39 original SVG files into this directory, run `python3 armenian/download_images.py` from the repository root. The page uses the original Wikimedia URL when a local file is absent.

## Supplemental traditional letter

`hiwn-lower.svg` is an adaptation of [Ու handwritten.svg](https://commons.wikimedia.org/wiki/File:%D5%88%D6%82_handwritten.svg) by そらみみ, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The final connected lowercase ւ component was isolated from the original path, and the guide lines/viewBox were adjusted to enlarge the letter. This is not an independent standalone handwriting photograph. The uppercase Ւ reference on the page is printed only; no independent uppercase handwriting was found in this image set. The original `Ու_handwritten.svg` remains unmodified.
